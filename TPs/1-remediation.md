# TP1 : Remédiation

## 1. Conception

On souhaite stocker une liste de produits.
Chaque produit peut être stocké (en un certain nombre d'exemplaires) dans un ou plusieurs entrepôts.
Chaque entrepôt se situe dans un bâtiment.

Un produit est défini par son nom, son code produit (unique), son prix unitaire.
Chaque entrepôt et bâtiment possède un nom.

Dressez le dictionnaire de données, ainsi que le MCD/MLD et le diagramme UML de ce système.
